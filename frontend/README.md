# HiveGrid frontend

HiveGrid is a responsive React, TypeScript and Vite frontend for the Society of Energy Agents simulation. The Overview, Simulation Studio, Home Agents, Activity Log, and resident request approval workflow connect to the Python FastAPI simulator. Login, invitations, and some administration views remain local frontend demonstrations.

## Run locally

Requirements: Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Start the backend separately on port 8000; Vite proxies API calls there. Set `HIVEGRID_API_TARGET` to use a different backend URL. To create the production build served by FastAPI, run `npm run build`.

## What is included

- Overview and Society Command Center with demo metrics and Recharts visualizations.
- Home Agents with search, status and solar filters, sorting, and a household detail panel.
- Energy Network visualization with interactive home and agent nodes.
- Simulation Studio with scenario controls, sliders, speed, timeline, and sample comparisons.
- Resident preference requests with structured temperature, EV, and battery constraints. Admin approval applies supported constraints to the active simulation through its safety checks.
- Activity Log filters and minimal Settings.
- Backend API adapter in `src/services/backend.ts` for simulation control and live simulator data.

Simulator measurements are generated by synthetic profiles in the Python backend. They are not live meter or utility readings. Some portal forms and secondary views still use local sample data.

## Portal demonstration

The welcome screen offers separate Society Admin and Resident demo access. The mock role session and invitations are stored in browser local storage; they are not real authentication or a security boundary. Resident requests are stored in the backend SQLite database and shared by the resident and admin portals. Applying a request requires a running simulation. The backend enforces supported temperature, EV, and battery reserve constraints; other preference text is retained for review and explicitly marked as unenforced.
